# MVP 범위

## 목표

MVP는 사용자의 상황을 수집하고, 출처가 있는 정책 원문과 구조화 조건을 기준으로 결혼·신혼부부 지원정책의 신청 가능 상태를 설명하는 것이다.

## 포함 기능

- 사용자 상황 입력과 답변 정규화.
- 정책 후보 검색.
- 구조화 조건 기반 자격판정.
- 충족, 불충족, 확인 필요 조건 표시.
- 정책 원문 근거와 정책 버전 표시.
- 부족 정보 재질문.
- 답변 충돌 처리.
- 정책 변경에 따른 `STALE` 처리.
- 신청 서류 안내.
- 개발용 정책 확인 도구 또는 최소 관리자 확인 기능.

## 제외 기능

- 행정기관 신청 대행.
- 정부 사이트 계정 연동.
- 주민등록, 소득, 자산 자동 조회.
- 금융기관 계좌 연결.
- 실제 서류 진위 검증.
- 정책 수혜 또는 지급 보장.
- 모든 지역과 모든 정책의 실시간 수집.
- LLM 단독 최종 자격판정.
- 초기 Kubernetes, MSA, Multi-Agent 구조.

## 성공 기준

- 정보 부족을 부적격으로 처리하지 않는다.
- 정책 원문과 구조화 조건을 판정 근거로 연결한다.
- 정책 버전 변경 시 기존 판정을 최신으로 유지하지 않는다.
- 답변 충돌 시 관련 판정을 재확인 전까지 확정하지 않는다.

## 기술적 완료 조건

- 로컬에서 애플리케이션이 실행된다.
- Health Check가 동작한다.
- 외부 인프라 없는 최소 테스트가 통과한다.
- README 실행 명령과 실제 구조가 일치한다.

## 운영상 제약

정책 데이터 공급처, 정책 구조화 검증 방식, 운영 Secret 관리 방식, 개인정보 보존 기간은 아직 미확정이다.

## 정책 데이터 범위

Phase 0에서는 정책 데이터의 실제 수집과 저장소를 구현하지 않는다. 정책 원문, 버전, 원문 해시, 구조화 조건, 근거 위치를 추적해야 한다는 계약만 문서화한다.

## 법적·행정적 한계

서비스의 판정은 사용자가 제공한 정보와 수집된 정책 기준에 따른 안내이며, 실제 행정기관의 최종 심사 결과를 보장하지 않는다.
