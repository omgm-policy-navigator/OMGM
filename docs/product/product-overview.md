# 제품 개요

## 배경

「나만 결혼해?」는 결혼을 준비하거나 신혼생활을 시작한 사용자가 중앙정부, 지방자치단체, 공공기관의 결혼·신혼부부 지원정책을 탐색하고 자신의 신청 가능성을 이해하도록 돕는 서비스다.

정책 정보는 기관별로 흩어져 있고, 조건 표현과 제출서류가 정책마다 다르다. 혼인 상태, 거주지, 소득, 자산, 주택 소유 여부 같은 조건을 함께 판단해야 하므로 사용자가 스스로 자격을 확인하기 어렵다.

## 해결 방식

서비스는 사용자 상황을 대화형으로 수집하고, 정책 원문과 구조화된 조건을 비교해 자격 상태를 계산한다. 결과에는 신청 가능 상태, 충족 조건, 불충족 조건, 확인 필요 조건, 제출서류, 원문 출처, 정책 버전을 함께 제공한다.

LLM은 사용자 질문 이해, 정책 원문 구조화 보조, 결과 설명 생성에 사용할 수 있지만 최종 자격 상태는 구조화 조건과 사용자 정보를 비교한 결정론적 판정 결과를 따른다.

## 핵심 사용자

- 예비부부: 혼인신고 전이거나 결혼 준비 중인 사용자.
- 신혼부부: 혼인신고를 완료했고 혼인 기간, 거주지, 소득, 주택 여부에 따라 정책을 찾는 사용자.
- 정보가 불완전한 사용자: 자신의 소득, 자산, 세대 상태, 주택 여부를 정확히 모르는 사용자.
- 운영 관리자: 정책 원문, 버전, 수집 상태, 구조화 결과, 판정 규칙, 변경 이력을 관리하는 사용자. Phase 0 구현 범위에는 포함하지 않는다.

## 핵심 가치

- 정보 부족을 부적격으로 처리하지 않는다.
- 정책 원문과 구조화 조건을 판정 근거로 사용한다.
- 사용자 답변 충돌과 정책 변경을 추적한다.
- 적용 조건과 부족한 정보를 함께 설명한다.
- 행정기관 최종 심사와 서비스 판정을 명확히 구분한다.

## 보장하는 것

- 현재 확보한 사용자 정보와 정책 조건 기준의 신청 가능 상태.
- 판정에 사용된 정책 버전과 근거.
- 부족하거나 충돌하는 정보의 재확인 필요성.

## 보장하지 않는 것

- 행정기관의 최종 승인, 지급, 수혜 보장.
- 모든 지역과 모든 정책의 실시간 수집.
- 정부 사이트 계정 연동이나 실제 신청 대행.
- 소득·자산 자동 조회 또는 서류 진위 검증.

## 용어

- 정책 원문: 기관이 게시한 공고문, 안내문, 신청 페이지 등 출처가 있는 자료.
- 구조화 조건: 정책 원문에서 추출한 비교 가능한 자격 기준.
- 판정 상태: `ELIGIBLE`, `INELIGIBLE`, `NEEDS_CONFIRMATION`, `STALE` 등 자격 계산 결과.
- RAG: 정책 후보와 근거 원문을 검색해 판정과 설명에 연결하는 검색 기반 생성 흐름.
