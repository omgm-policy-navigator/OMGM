# AI A6 품질·안전 통제 기준선

## 실행 범위

이 결과는 외부 모델을 호출하지 않는 결정론적 회귀 기준선이다. 합성 입력 5건을 실제 A2 파서·검토, Rule Engine, A4 검색과 A5 생성 경계에 통과시켜 actual 관측값을 생성한다. 운영 정확도나 실제 사용자 분포에 대한 통계적 품질을 의미하지 않는다.

## 실패 게이트 검증

테스트는 별도의 의도적 회귀 관측값으로 Rule 결과 변경 1건, 무근거 Claim 1건, unsafe failure 1건을 주입하고 전체 결과가 실패하는지 확인한다. 필수 Citation 하나를 누락하면 Precision이 100%여도 Recall 50%로 실패한다. 또한 RAG 실제값을 nullable로 둔 Case는 실패 건수로 변환되지 않고 Coverage를 낮추며, Coverage 미달로 전체 게이트가 실패한다. 부분 Suite는 적용 지표만 평가하지만 A6 통합 게이트는 9개 지표 모두를 요구한다.

## 제한사항

- 조건 추출 기준선은 합성 canonical key/value의 완전 일치를 측정한다.
- RAG Recall과 Citation 정확도는 D5 기반 소규모 통제 Case이며 전체 38개 정책의 실제 질의 분포를 대표하지 않는다.
- Prompt Injection은 알려진 합성 공격 Case 기준이다. 새로운 공격 유형은 관측값을 추가해 지속 검증해야 한다.
- 실제 Ollama 지연시간, GPU 메모리 압력과 비결정적 출력 품질은 이 기준선에 포함하지 않는다.
