# ADR 작성 기준

ADR은 되돌리기 어렵거나 여러 대안 중 명시적 선택이 필요한 결정이 있을 때만 작성한다.

## 작성 조건

- 저장소 또는 서비스 경계 변경.
- 데이터 소유권 변경.
- 정책 판정 방식 변경.
- LLM과 결정론적 로직의 책임 변경.
- 보안상 중요한 저장·암호화 방식 결정.
- 되돌리기 어려운 인프라 선택.

## 파일명

`docs/adr/0001-short-title.md` 형식을 사용한다.

## 구조

```text
상태
맥락
결정
대안
선택 이유
결과
위험
재검토 조건
관련 문서
```

Phase 0의 단일 저장소 폴더 정렬과 FastAPI 최소 서버 구성은 확정 아키텍처를 반영한 초기 실행 기반이므로 별도 ADR로 기록하지 않는다.
