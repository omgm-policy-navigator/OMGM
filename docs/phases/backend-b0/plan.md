# Backend Phase B0 Plan

## Goal

Establish FastAPI backend responsibility, contracts, and development structure before implementing additional product features.

## Scope

- Decide the modular monolith structure.
- Define API list and mockable contracts.
- Define database access rules.
- Define exception response contracts.
- Establish test and documentation standards.

## Completion Criteria

- All planned backend features are mapped to owning modules.
- API draft and error codes are defined.
- Mock contracts are ready so backend work can proceed without other areas.
- Phase B0 goal, implementation scope, and completion criteria are recorded in this phase folder.

## Out of Scope

- SQLAlchemy models and Alembic migrations.
- Production policy search, RAG, LLM client, graph projection, saved policy, and notification implementations.
- Splitting backend into multiple services.
